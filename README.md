# Homebrew tap

Install [Fast Trackpad](https://github.com/lattecor/fast-trackpad), a macOS utility that reduces the sluggish feel of Magic Trackpad over USB and Bluetooth:

```sh
brew install lattecor/tap/fast-trackpad
fast-trackpad gui
```

Requires macOS 15+ and Apple developer tools with Swift 6. Installation builds the app locally; it does not apply trackpad settings.

Update with `brew update` followed by `brew upgrade lattecor/tap/fast-trackpad`.
